# 4. Website Theme

The website should communicate **executive intelligence**, rather than looking like a conventional AI landing page.

## Hero

Dark Midnight canvas.

**Large statement**: Your Executive Intelligence. Operating as One System.

**Supporting copy**: Nyxor brings decisions, priorities, knowledge, meetings, communications and AI into one executive operating environment.

**Primary CTA**: Enter Nyxor
**Secondary CTA**: See How It Works

The orbital V can exist as an oversized, subtly illuminated background object.

## Homepage architecture

1. Hero
2. Executive problem
3. Nyxor operating model
4. Command Center preview
5. Executive AI
6. Decision Intelligence
7. Memory / Second Brain
8. Meetings & communication
9. Integrations
10. Security/trust
11. Use cases
12. Final CTA

Visual rhythm should alternate between dark immersive sections and highly restrained white/light sections.

---

**Implementation note**: this is a considerably larger homepage architecture (12 sections) than the currently-approved landing-page plan's 8 sections, and reframes copy around "Nyxor operating model / Executive AI / Decision Intelligence / Memory" concepts not yet named that way in the product (NYXOR's actual built features are: onboarding → Executive Intelligence Profile + Voice Profile → agent workforce → HITL-governed dashboard). Reconcile which framing to ship with before writing final landing-page copy — this system's "Memory / Second Brain" and "Decision Intelligence" sections describe positioning language, not necessarily features that exist yet.
