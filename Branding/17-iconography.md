# 17. Iconography

Create a proprietary **Vex Glyph** family.

## Style

- 2px rounded stroke
- 24×24 base grid
- Geometric
- Minimal
- Slight orbital influence

## Core icons

Command · Priority · Decision · Memory · Meeting · People · Knowledge · Signal · Risk · Opportunity · Automation · Delegation · Analytics · VEX · Voice · Briefing

The orbit/node motif should subtly appear in intelligent or AI-related icons.

---

**Implementation note**: `apps/web` has no icon library today. The approved landing-page plan already proposes adding `lucide-react` as the one new dependency — a proprietary icon set (Vex Glyph) is a larger, separate undertaking (custom SVG design work) than that plan's scope. Lucide can serve as a placeholder/interim icon system until a real Vex Glyph set exists.
